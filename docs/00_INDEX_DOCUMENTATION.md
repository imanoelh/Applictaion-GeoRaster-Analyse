## Convention de fiabilité

- **Implémenté** : vérifié directement dans le code courant.
- **Testé localement** : couvert par une commande exécutée à la date indiquée dans le document concerné.
- **Dépendant de GEE** : implémenté, mais non validé en ligne pendant cette mission.
- **Expérimental** : structure présente, workflow incomplet.
- **Feuille de route** : non implémenté.
